# Известные проблемы и ограничения

## Не реализовано

- `make_engine()` — в `main.cpp` используется временная заглушка, возвращающая `nullptr`. Необходимо реализовать полноценный движок работы с БД через SOCI/POCO.
- Обработка `leader_ready` после ожидания лидера — секция выключения (стоп таймера регистрации) выполняется сразу после цикла ожидания, но основная логика работы сервиса после подключения к лидеру отсутствует.
- `selftest_ok` — задекларирована, но не используется.

## Архитектурные

- `SignalWaiter` дублирует функциональность из `services/signaling_cpp/app/signal_waiter.h`. Рассмотреть вынос в общую библиотеку.
- `get_instance_identifier()` — использует свой собственный RNG вместо `make_oid()` из `oid.h`.

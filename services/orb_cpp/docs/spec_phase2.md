1. реализация orb_client в lunaricorn\cpp. поддерживаеый api сервера надо быдут расширить для поддержания расширенных функций клиента

# предварительные изменения сервера
http endpoint должен поддерживать gzip сдатие контента, клиент будет его принудительно использовать
сервер должен вести статистику обращений через апи и объёмов переданных данных. он должен выводить эту статистику в консоль раз в минуту

# функционал клиента:

клиентскому коду предоставляется класс orb_client для установки соединения с orb для инициализации класса используется url orb сервера
клиент по таймеру проверяет доуступность сервера используя /health проверку
клиент предоставляет функции для поиска объектов по id и по тегам если поиск был успешен, то клиенту возвращается особый объект orb_object
клиент имеет функцию create выдавая пустой orb_object с новым сгенерированным id для этого в интерфейсе сервера должна экспортироваться в api функция генерации id

# манипулятор объектом


orb_object привязан к клиенту, который его породил и использует его внутренние интерфейсы для работыс апи сервера. для этого он использует интерфейс IOrbController реальная реализация которого находится в orb_client
orb_object не позволяет менять свой id считается, что объект всегда валиден (но на всякий случай нужно добавить функцию check которая проверяет, что объект всё ещё существует в базе)


orb_object позволяет получать и менять все основные поля мета объекта (parent, decription и тд. ) кроме поля указывающего на наличие блоба. это поле должно управляться автоматически внутри сервера основываясь на работе с блобами. все эти поля е кешируются и каждый раз запрашиваются с сервера

orb_object имеет методы store и load для загрузки и выгрузки блоба методы прнимают или возвращают boost json

orb_object кроме прямого управления id связей (parent/prev/next) имеет одноимённые функции позволяющие следовать по ссылкам эти функции должны возвращать другой orb_object на который ссылается поле

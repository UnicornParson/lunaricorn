# Problems: Известные проблемы и технический долг

## Критические

### P1: Reconnect логика отсутствует
- **Статус:** ❌ Не реализовано
- **Файл:** `app/raw_endpoint.cpp`, `app/raw_endpoint.h` (RE_Client)
- **Влияние:** При разрыве соединения клиент должен переподключиться вручную. Нет автоматического восстановления.
- **Рекомендация:** Добавить exponential backoff reconnect в RE_Client или отдельный reconnect manager.

### P2: Нет unit-тестов
- **Статус:** ❌ Не написаны
- **Файл:** `test_client/`
- **Влияние:** Любое изменение кода может сломать существующую логику без возможности обнаружить это автоматически.
- **Рекомендация:** Написать unit-тесты для SignalingProto (сериализация/десериализация), MessageStorage (CRUD), RawEndpoint (protocol handling), SignalingEngine (подписки/диспатч).

### P3: processQueryRequest не связан с SignalingEngine
- **Статус:** ⚠️ Заглушка
- **Файл:** `app/raw_endpoint.cpp::processQueryRequest()`
- **Проблема:** Отправляет ACK, но не выполняет поиск через `engine->findEvents()` или `engine->findEventsByType()`.
- **Влияние:** Клиенты не могут получить историю событий через raw-протокол.
- **Рекомендация:** Связать с SignalingEngine, парсить query-параметры из payload.

## Средние

### M1: Docker healthcheck отсутствует
- **Статус:** ❌ Не реализовано
- **Файл:** `services/docker-compose.yaml`, `services/signaling_cpp/Dockerfile`
- **Влияние:** Docker не может автоматически определить, что сервис запущен и готов принимать соединения.
- **Рекомендация:** Добавить healthcheck через `GET /health` HTTP endpoint (curl или аналогичный скрипт).

### M2: Нет README.md
- **Статус:** ❌ Не создан
- **Файл:** `services/signaling_cpp/README.md`
- **Влияние:** Разработчики не имеют инструкций по сборке, настройке и запуску.
- **Рекомендация:** Создать README.md с разделами: prerequisites, build, configuration (переменные окружения), run, docker, testing.

### M3: STATUS.md устарел
- **Статус:** ⚠️ Требует обновления
- **Влияние:** Глобальный статус проекта не отражает текущее состояние signaling_cpp.
- **Рекомендация:** Обновить корневой `doc/STATUS.md`.

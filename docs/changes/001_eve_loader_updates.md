## Изменения в коде
Добавлены новые модели SQLAlchemy для справочников (dimension tables):

### Новые таблицы
1. **`dim_eve_regions`** — справочник регионов EVE Online
2. **`dim_eve_constellations`** — справочник созвездий (связь region → systems)
3. **`dim_eve_solar_systems`** — справочник солнечных систем (включая security_status и security_class)
4. **`dim_eve_categories`** — справочник категорий предметов
5. **`dim_eve_groups`** — справочник групп предметов
6. **`dim_eve_types`** — справочник типов предметов (названия, описания)

### Новая функциональность
- `update_region_reference()` — рекурсивная загрузка иерархии Region → Constellations → Solar Systems с помощью PostgreSQL UPSERT
- `update_types_reference()` — ленивая загрузка справочника предметов (только те, что есть в ордерах), рекурсивно подгружает groups и categories
- Используются SQLAlchemy `pg_insert` с `on_conflict_do_update` для обновления существующих записей
